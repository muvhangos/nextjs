## 🚀 Running a Chapter

Each chapter is maintained as an individual Next.js project.

First navigate into the chapter you want to work with.

For example:

```powershell
cd chapter30
```

Install the dependencies:

```powershell
npm install
```

Start the development server:

```powershell
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

## 📦 Installing Dependencies

Dependencies are maintained separately for each chapter.

For a specific chapter:

```powershell
cd chapterXX
npm install
```

Replace `XX` with the chapter number.

For example:

```powershell
cd chapter20
npm install
```

## 🔧 Building for Production

To create a production build:

```powershell
npm run build
```

To run the production build:

```powershell
npm start
```

## 🔐 Environment Variables

Some chapters may require environment variables for external services or databases.

Create a local `.env.local` file when required.

**Do not commit passwords, API keys, database credentials, or other secrets to GitHub.**

Example:

```env
DATABASE_URL=your_database_connection_string
API_KEY=your_api_key
```

Environment files containing secrets should remain excluded through `.gitignore`.
